# Mihir Panchal — Portfolio

A responsive static portfolio for GitHub Pages. No build step or dependencies.

## Preview

Run `python3 -m http.server 4187` in this folder, then open http://localhost:4187.

## GitHub Pages

Publish these files in `portfolio`. In the repository's Settings → Pages, select **Deploy from a branch**, **main**, **/ (root)**. The site will be available at https://mehere14.github.io/portfolio/ after GitHub's deployment finishes.

The same files also work in a project repository; all local asset paths are relative.

Reefnote's image is a screenshot from its repository; the Screenshot Generator illustration is a CSS composition.
